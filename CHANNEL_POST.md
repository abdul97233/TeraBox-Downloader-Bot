# 🚀 TeraBox Bot v3.8 — Major Update!

## 🎯 What's New?

### ⚙️ **Fully Customizable Limits** (Owner only)
- `/setlimit free 20` — free user hourly limit
- `/setlimit premium 0` — premium limit (0 = unlimited)
- `/maxfiles 5` — max files per link
- `/setcooldown 5` — cooldown between downloads
- `/userlimit <user_id> <n>` — custom limit per user!

### 👑 **Owner = Zero Limits**
No rate limits, no file limits, no cooldowns.

### 🔗 **Multi-Link Download**
Send multiple links in one message → bot downloads all!

### 👤 **Tap-to-Contact New Users**
Admin notifications now have clickable names:
`[Name](tg://user?id=123456789)` — works even without username!
